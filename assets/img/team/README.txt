Team photos
===========

Drop the portraits here with these exact filenames:

  ivan-vican.jpg
  marino-vican.jpg     <-- awaiting Marino's photo
  duje-musura.jpg

Specs
-----
  Aspect ratio : 4:5 (portrait)
  Size         : 800 x 1000 px minimum
  Format       : .jpg (or change the src in index.html to .webp)
  Weight       : keep under ~200 KB each

Photos are shown in full colour, so supply them already colour-corrected.
The only treatment the site applies is a gentle zoom on hover.

Until a file exists, that card automatically falls back to the person's
initials plus a "PHOTO PENDING" marker — nothing breaks.
